# 关于本站

## 项目简介

CTF在线工具导航是一个收集整理CTF(Capture The Flag)比赛中常用在线工具的网站，旨在帮助CTF选手快速找到需要的工具，提高解题效率。

## 工具分类

本站将工具分为以下几个大类：

- **编码解码**: Base系列、URL编码、十六进制等常见编码格式
- **加密解密**: 对称加密、非对称加密、哈希函数等密码学工具
- **Web工具**: SQL注入、XSS、命令注入等Web安全测试工具
- **逆向工具**: 反编译、反汇编、调试等二进制分析工具
- **杂项工具**: 隐写分析、文件分析、密码破解等其他实用工具

## 技术栈

本站使用以下技术构建：

- **静态站点生成器**: [MkDocs](https://www.mkdocs.org/)
- **主题**: [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)
- **部署**: GitHub Actions + GitHub Pages
- **语言**: Markdown + Python

## 特点

- 📱 响应式设计，支持移动设备
- 🌓 支持亮色/暗色主题切换
- 🔍 全站搜索功能
- 🚀 快速加载，静态网页
- 📝 持续更新

## 贡献指南

欢迎为本项目贡献！你可以通过以下方式参与：

### 提交新工具

如果你发现了有用的在线工具，欢迎提交Issue或Pull Request，请提供：

- 工具名称
- 工具链接
- 工具简介
- 适用分类

### 更新失效链接

如果发现某个工具链接失效，请提交Issue告知我们。

### 改进文档

发现文档错误或有改进建议，欢迎提交PR。

### Pull Request流程

1. Fork本仓库
2. 创建你的特性分支 (`git checkout -b feature/AmazingFeature`)
3. 提交你的修改 (`git commit -m 'Add some AmazingFeature'`)
4. 推送到分支 (`git push origin feature/AmazingFeature`)
5. 开启Pull Request
