# CTF在线工具导航 - 使用指南

## 🔍 搜索功能

### 如何搜索

**方式1**: 点击顶部搜索图标 🔍

**方式2**: 使用快捷键
- 按 `/` 或 `S` 键打开搜索
- 按 `ESC` 关闭搜索

### 搜索示例
- 工具名称: `CyberChef`, `Burp Suite`
- 技术术语: `Base64`, `RSA`, `SQL注入`
- 场景: `图片隐写`, `密码破解`

### 搜索功能特性
✨ 实时搜索建议  
🎯 智能中英文混合匹配  
🔦 结果高亮显示  
📱 移动端支持  
🔒 完全本地搜索，保护隐私

详细使用方法请查看 [搜索指南](search-guide.md)

## 💡 使用技巧

### 初学者建议
1. 从 [快速开始](quickstart.md) 了解基础
2. 使用搜索功能查找工具
3. 收藏常用工具链接
