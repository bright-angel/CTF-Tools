# URL编码

URL编码用于将特殊字符转换为URL安全格式。

## 在线工具

### URL Encode/Decode
**链接**: [https://www.urlencoder.org/](https://www.urlencoder.org/)

**功能**: URL编码和解码

**特点**:
- 支持单次和多次编码
- 自动识别编码类型
- 界面简洁直观

### CyberChef
**链接**: [https://gchq.github.io/CyberChef/](https://gchq.github.io/CyberChef/)

**功能**: 万能数据处理工具

**特点**:
- 支持URL编解码
- 可与其他操作组合使用
- 功能强大

###Burp Suite Decoder
**提示**: Burp Suite自带解码器

**特点**:
- 支持多种编码互转
- 集成在渗透测试工具中
- 可批量处理

## 编码规则

URL编码将特殊字符转换为 `%XX` 格式，其中XX是字符的十六进制ASCII码。

**常见字符编码对照**:

| 字符 | URL编码 | 说明 |
|------|---------|------|
| 空格 | %20 或 + | 空格的两种表示 |
| ! | %21 | 感叹号 |
| # | %23 | 井号 |
| $ | %24 | 美元符号 |
| % | %25 | 百分号自身 |
| & | %26 | 和号 |
| / | %2F | 斜杠 |
| = | %3D | 等号 |

## 双重URL编码

在某些绕过场景中，可能需要进行两次或多次URL编码：

```
原文: ' OR '1'='1
一次编码: %27%20OR%20%271%27%3D%271
二次编码: %2527%2520OR%2520%25271%2527%253D%25271
```

!!! warning "注意"
    在Web渗透中，双重或多重URL编码常用于WAF绕过。
