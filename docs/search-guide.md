# 搜索功能说明

## 搜索功能已启用 ✅

本网站已内置强大的搜索功能，支持中英文混合搜索。

## 如何使用搜索

### 方式1: 点击搜索图标
1. 点击页面顶部的 🔍 搜索图标
2. 在弹出的搜索框中输入关键词
3. 实时显示匹配结果

### 方式2: 键盘快捷键
- 按 `/` 键或 `S` 键快速打开搜索
- 按 `ESC` 键关闭搜索框

## 搜索功能特性

### ✨ 实时搜索建议
输入时即时显示相关结果，无需回车

## 搜索不到结果？

如果搜索不到想要的内容：

1. **检查拼写**: 确认关键词拼写正确
2. **简化关键词**: 使用更简短的词语
3. **换个说法**: 尝试使用同义词或英文
4. **浏览导航**: 通过左侧导航栏浏览分类
5. **提交反馈**: [提Issue](https://github.com/yourusername/ctf-online-tools/issues)

## 开发者信息

### 搜索引擎
- 基于 MkDocs Material 内置搜索
- 使用 lunr.js 搜索库
- 支持中文分词

### 索引构建
- 自动构建搜索索引
- 包含所有页面内容
- 每次部署自动更新

### 自定义配置
在 `mkdocs.yml` 中的搜索配置：

```yaml
plugins:
  - search:
      lang:
        - zh  # 中文支持
        - en  # 英文支持
      separator: '[\s\-\,\.\!\?\:]+'  # 分词规则

theme:
  features:
    - search.suggest   # 搜索建议
    - search.highlight # 结果高亮
    - search.share     # 分享搜索
```
