## 古典密码

### Caesar密码
**原理**: 字母移位

**在线工具**: [https://www.dcode.fr/caesar-cipher](https://www.dcode.fr/caesar-cipher)

**示例**:
```
明文: HELLO
密文(ROT3): KHOOR
密文(ROT13): URYYB
```
